05 / BEHIND THE PROJECT

从汽车摄影，
长出来的小工具。

Fang Dian / 方典产品需求 · 架构设计 · 验证与发布

汽车照片准备分享时，去除车牌是一项重复而细致的工作：需要照顾隐私，也希望留下车身和格栅的质感。

这个项目把识别、局部修复和人工复核放在一个离线桌面工具里。自动化负责重复步骤，最终效果仍由使用者确认。

代码采用 AI 辅助编程，作者负责需求、架构与发布代码审查。源码公开，采用非商用许可。

了解它如何工作 ＋

检测结果生成局部遮罩，修复模型填充区域，之后由编辑器复核。标准版使用 ONNX Runtime 与 LaMa；高清模式使用 Big-LaMa 组件，桌面界面使用 WebView2。

填充是根据周边内容生成的结果，不能恢复被车牌遮挡的真实表面。复杂反光、格栅和小车牌需要特别复核。

06 / GOOD TO KNOW

使用前，你可能想知道。

照片会上传吗？＋

软件的照片识别、修复与复核都在本机完成，无需上传照片。本网页仅展示预先准备的示例，没有上传照片或在线修复功能。

会覆盖我的原图吗？＋

处理结果另存，原图保留。输出照片保持输入尺寸；最终文件的压缩和元信息仍取决于导出设置。

所有车牌都能自动检测到吗？＋

不能保证。远处小车牌、倾斜、遮挡和反光可能造成漏检或误检。可以在复核编辑器调整区域，并选择保留或消除。

高清修复为什么更慢？＋

更大的局部区域需要更多计算与内存。高清修复默认使用自动模式，可调整处理上限。当前版本在 CPU 环境验证，实际速度取决于照片尺寸与电脑配置。

纹理增强会一直生效吗？＋

不会。开关默认开启，但仅在邻近细节适合时补充纹理；强结构边缘、颜色不匹配或来源不足会自动跳过。开关与强度均可调整。

商业照片处理可以直接使用吗？＋

当前许可仅授予个人及非商业用途。用于商业摄影或服务前，请联系作者确认授权。阅读完整许可。

遇到问题，怎样反馈？＋

可以在 GitHub Issues 描述版本、问题和复现步骤。分享照片前，请检查隐私并确认有权公开。
