## v0.3.0 监视文件夹

- 版本：`v0.3.0` 子 spec 1。
- WatchFolderService 基于 Windows ReadDirectoryChangesW 实时感知新增或修改的照片（JPEG/PNG/TIFF），文件稳定后入队处理。
- 启动扫描在后台线程异步进行，可在 UI 取消；取消后已收集的条目仍会处理。
- 取消当前批处理时，会同时清空监视队列中的待处理条目，正在处理的单张照片安全完成。
- 网络驱动器（UNC 路径和映射网络盘）在添加和启动扫描时均被拒绝，UI 上标记错误状态。
- 任务数据库 schema 升级到 v5，新增 `file_mtime` 和 `file_size` 列用于去重；旧库自动迁移。
- `settings.json` 新增 `watch_folders` 字段（path、enabled、added_at），兼容旧设置文件。
- 性能预算：入队延迟 ≤ 2 秒（文件稳定后），启动扫描 ≤ 3 秒（典型规模）。
- Python 单元测试、前端测试和集成测试覆盖核心路径。

## v0.3.0 批量后处理

- 版本：`v0.3.0` 子 spec 2。
- 处理完成后自动重命名、叠加水印、填写 EXIF 元数据；在设置页“批量后处理”区块配置，默认关闭。
- NamingTemplate 解析命名模板，支持 `{original}`、`{ext}`、`{seq:03}`、`{client}`、`{date}` 占位符；`{seq:03}` 遇同名冲突自增。
- WatermarkRenderer 渲染文字水印与图片水印，支持类型切换（text/image）；图片水印支持本地文件选择（PNG/JPG/BMP/TIFF）、缩放比例（相对原图短边 5%–100%）、透明度和 9 宫格位置；水印图片缺失时自动跳过并保留原结果。
- ExifWriter 写入 Artist、Copyright、ImageDescription；仅 JPEG/TIFF 生效，PNG 自动跳过。
- PostProcessor 编排上述步骤，单图后处理失败不阻塞批处理，保留原消除结果。
- 任务数据库 schema 升级到 v6，新增 `post_processed_output` 列记录后处理输出路径；旧库自动迁移。
- 性能预算：单图后处理增量 ≤ 500ms。
- Python 单元测试、前端测试和集成测试覆盖命名模板解析、文字/图片水印渲染、EXIF 写入和失败回退路径。
- 顶部栏新增“关于”对话框，展示软件版本、AI 运行时、数据库 schema 版本和版权信息；通过点击版本号按钮触发。

## GitHub 签名 secrets

- `WINDOWS_SIGN_CERTIFICATE_BASE64`：PFX 文件的 Base64；
- `WINDOWS_SIGN_CERTIFICATE_PASSWORD`：PFX 密码。

正式 `v*` tag 只有在两项 secrets 可用、签名验证通过后才会创建 GitHub Release。
