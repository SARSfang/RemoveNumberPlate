# 高清修复

在设置中选择自动、标准或高分辨率。默认自动，局部裁剪超过 512 像素时尝试 Big-LaMa；标准模型继续可用。默认高清上限 1536，仅约束裁剪尺寸，输出照片尺寸保持不变。

纹理增强默认开启，强度 25%，可关闭。它从邻近有效区域迁移少量细节；强结构边缘、颜色不匹配或来源不足时自动跳过。它不能恢复车牌遮挡的真实表面。

## 运行组件

标准版不依赖 PyTorch。开发环境在 `.venv-hd` 安装 `requirements-hd.txt`，CPU 版 torch 可从 PyTorch 官方 CPU 索引安装。支持 CUDA 的 torch 安装完成后工作程序会优先使用 GPU；未实测的 GPU 路径不得声称已验收。

高清权重为 IOPaint 维护者 Sanster 分发的 Big-LaMa TorchScript 转换版，来源 https://github.com/Sanster/models/releases/download/add_big_lama/big-lama.pt 。发布者 MD5 为 e3aa4aaa15225a33ec84f9f4bc47e500；本地测得 SHA-256 为 344c77bbcb158f17dd143070d1e789f38a66c04202311ae3a258ef66667a9ea9。它不是原作者的原始 checkpoint 文件。适配器在运行前验证 SHA-256。

直接 ONNX opset 17 导出实测失败于 aten::fft_rfftn，因此首版采用独立工作程序，保持原始 FFT 推理。标准环境不加载 torch。

在独立高清环境安装 PyInstaller，然后运行 `packaging/build_hd_component.ps1` 生成可选离线组件。将组件内的 `hd-runtime` 与 `_internal` 合并到标准程序目录；高清权重位于 `_internal/models/big-lama.pt`。无需在用户机器安装 Python。组件包含模型及独立运行环境，体积比标准版大。

自动模式失败会提示回退；手动选择高分辨率模式失败不会静默回退。错误与各区域的模型、缩放比例、纹理处理原因写入日志。设置只允许在任务空闲时变更，变更后旧预览不可保存。

## 验证边界

真实照片对比保存在项目 output/hd-validation；无损输出用于检查遮罩外像素一致性。1024、1536、2048 放大裁剪仅为输入尺寸压力测试，不能充当原生高分辨率照片质量证据。完整打包离线测试及性能结果见后续验证记录。

CPU 打包工作程序实测（含启动和模型加载）：1024 约 9 秒，观察到的工作集峰值约 1.57 GiB；1536 约 15 秒、2.90 GiB；2048 约 24 秒、4.61 GiB。数据来自放大裁剪压力测试，仅包含工作程序内存，不含主程序的原图和输出缓存。GPU 路径未验收。

高清质量选项支持鼠标点击、左右方向键及 Home/End。纹理、水印、EXIF、批量后处理和监视目录均使用滑块开关，保留原生键盘操作。高清设置自动保存；后处理仍需点击其保存按钮。任务运行期间更改高清设置会被拒绝并恢复原值。
