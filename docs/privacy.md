# 隐私说明

## 本地处理

消除车牌的检测、掩码生成、图像修复和文件写入全部在本机完成。应用界面和 Python
桥接使用本地文件，不请求云端推理服务，不上传照片或 EXIF。

## 本机保存的数据

应用在 `%LOCALAPPDATA%\SARSfang\RemoveNumberPlate` 保存：

- `jobs.sqlite3`：任务标识、源/输出文件位置、状态、风险原因、检测框和人工掩码命令；
- `settings.json`：处理预设；
- `Logs\application.log*`：轮转运行日志。

数据库不保存照片像素或 OCR 车牌文字。当前产品不执行 OCR。

## 输出与元数据

结果写入源目录旁的 `车牌已消除` 文件夹，原片不会被覆盖。软件在格式允许时保留安全
的 ICC、DPI 和部分 EXIF，同时规范化方向；不保证复制所有厂商私有元数据。

## 诊断导出

诊断包只包含应用版本、Windows/Python/WebView2/ONNX 环境、处理预设、任务状态数量
和轮转日志。导出逻辑明确排除照片、完整文件路径和任务数据库。

## 卸载与删除

卸载程序只删除应用文件，不删除原片、输出照片或本机任务数据。需要彻底清除任务历史
时，请先退出应用，再自行删除
`%LOCALAPPDATA%\SARSfang\RemoveNumberPlate`。删除后无法恢复复核队列和历史记录。
