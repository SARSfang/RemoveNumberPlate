## 关键改进

- 统一按钮、图标按钮、数值输入、滑块和标签页的最小 40px 操作目标。
- 高缩放时压缩非必要标题说明，启动拖放区保持在可视区域内。
- 复核页窄屏隐藏辅助队列、工具栏分两行重排，上一张、下一张、跳过和确认均保留。
- 历史任务窄屏详情改为抽屉；支持关闭按钮、Escape 关闭和触发行焦点恢复。
- 设置页边缘扩展滑块提供百分比辅助文本、极端值警告和保存反馈。
- 清理未定义的 CSS 变量，统一边框和浮层色彩令牌。

## 交互与可访问性

- 主导航、原图/结果标签、复核预览标签和历史列表可由键盘访问。
- 范围控件通过 `aria-valuetext` 报读实际百分比或像素值。
- 历史详情具有可识别名称，关闭后焦点返回原任务行。
- 禁用操作使用一致的不可用光标；减少动态效果偏好继续受支持。
- 可见控件在审计视口中均达到至少 40 × 40 CSS 像素。
