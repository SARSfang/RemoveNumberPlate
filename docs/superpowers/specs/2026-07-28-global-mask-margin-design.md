# 全局车牌边缘扩展设置设计

日期：2026-07-28  
状态：已批准

## 目标

将车牌蒙版的默认边缘扩展从 `+8%` 调整为 `+35%`，并允许用户在设置页长期修改。自动批处理和单张调整编辑器使用同一个全局默认值。

## 已批准的产品规则

- 默认值：`+35%`
- 可设置范围：`-30%` 至 `+100%`
- 步进：`1%`
- 自动批处理和手动调整编辑器共享该默认值
- 修改设置只影响之后开始的任务
- 单张照片已保存的边缘调整继续覆盖全局默认值
- 超过 `+60%` 时提示可能覆盖车身细节，但允许保存

## 数据与兼容性

`settings.json` 增加 `mask_margin_ratio` 数值字段，内部以比例保存，例如 `0.35`。旧设置文件没有该字段时自动使用 `0.35`，无需迁移操作。无效或越界设置沿用现有恢复机制。

设置更新必须保留其他字段：修改处理预设不得重置边缘扩展，修改边缘扩展也不得重置处理预设。

## 自动处理

创建批处理器时，将当前设置中的 `mask_margin_ratio` 注入 `PlateMaskPolicy`。批次运行期间不允许修改该设置，避免同一批照片使用不同默认值；批次结束后可修改，新处理器使用新值。

## 单张调整

后端在加载调整照片时返回当前全局默认值。编辑器先以该值初始化，再按顺序应用照片已有的调整命令；若已有 `set_margin`，照片自身值优先。因此已保存的调整不会被全局设置覆盖。

编辑器范围同步扩展为 `-30%` 至 `+100%`。恢复自动框仅恢复形状，不改变已选边缘值。

## 设置界面

处理设置区域增加“默认边缘扩展”控件：

- 范围滑块和数值输入使用百分比展示
- 初始显示已保存值
- 用户确认修改后调用桌面 API 保存
- `+61%` 至 `+100%` 显示温和风险提示
- 保存失败时恢复此前值并显示原因

## 校验

前后端都限制在 `-30%` 至 `+100%`，后端为最终可信边界。测试覆盖：

- 新默认值和设置文件向后兼容
- 两个设置字段互不覆盖
- 自动处理器收到所选蒙版策略
- 编辑器使用全局默认值且照片命令可覆盖
- 上下限接受、越界拒绝
