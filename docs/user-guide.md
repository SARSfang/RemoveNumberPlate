# 消除车牌用户指南

**作者**：Fang Dian（方典）<fangdian@tju.edu.cn>

## 0. 主题与配色

应用会自动跟随 Windows 系统主题切换：

- **深色模式**（默认）：底色深灰 `#0a0a0a`，适合夜间或低光环境
- **浅色模式**：底色纯白 `#ffffff`，适合白天或高光环境

切换方式：打开 **Windows 设置** → **个性化** → **颜色** → 选择"深色"或"浅色"模式，应用立即切换，无需重启。

## 1. 开始批处理

1. 打开“消除车牌”。
2. 把照片或文件夹拖到批处理页，也可以使用“选择照片/选择文件夹”。
3. 任务开始后，中央显示单张大图，底部胶片带显示整批照片。
4. 使用“原图 / 处理结果”切换预览；结果尚未生成时会自动回到原图并说明原因。
5. 点击胶片带中的照片可固定预览；按 `F` 恢复跟随当前处理项。
6. 任务完成后，在右侧详情中打开源目录旁的 `车牌已消除` 文件夹。

支持 JPEG、PNG、TIFF；扫描文件夹时会递归寻找照片。软件不会覆盖原片，同名结果会
自动追加 `_clean_2`、`_clean_3` 等后缀。

### 批处理快捷键

- `Ctrl+O`：添加照片；
- `← / →`：浏览胶片带；
- `Home / End`：选择第一张或最后一张；
- `1 / 2`：切换原图或处理结果；
- `F`：恢复自动跟随。

批次运行时“添加照片”保持可见但会禁用，避免改变正在执行的任务队列。

## 2. 理解任务状态

- **已完成**：已生成结果，可以打开输出目录。
- **待复核**：检测存在低置信度、贴边、重叠等风险，原片尚未修改。
- **未发现车牌**：自动检测没有找到车牌；可以在任务历史中选择“手动标记”。
- **失败**：单张照片处理失败，不会中断整个批次；可在任务历史中重新处理。
- **排队中**：应用上次被中断的任务，可在任务历史中重新处理。

## 3. 调整每张照片的消除区域

在批处理主预览中选择任意一张已经停止处理的照片，点击右上角“调整区域”。低置信度、
贴边或异常检测照片也可以从“待复核”集中进入同一个编辑器。

- 四点框：分别拖动四个角点，让边线贴合车牌透视；
- 边缘：默认向外增加 8%，可在 -15% 到 +35% 间按 1% 调整；
- 新增车牌框：一张照片有多个车牌或漏检时点击新增；
- 画笔/橡皮擦：精修掩码边缘；
- 删除车牌框：移除误检区域；
- 撤销、重做和恢复自动框；
- 鼠标滚轮缩放，按住空格拖动画布；
- `[` / `]` 或按钮切换上一张、下一张。

点击“生成临时预览”后，AI 结果只保存在应用缓存，不会进入输出文件夹。可以在
“原图与区域 / 临时结果”间切换，选择“继续调整”或“保存新结果”。只有保存时才在
`车牌已消除` 文件夹生成新版本；原图和旧结果都不会覆盖。退出或重新编辑会让旧临时
预览失效。

## 4. 免安装测试版

开发测试时不必反复安装和卸载。关闭正在运行的软件后，在项目根目录执行：

```powershell
.\packaging\build_preview.ps1
```

以后始终双击根目录的 `启动测试版.cmd`。它只启动 `dist\preview` 中的固定测试版，
不会写安装记录或创建卸载项。安装程序只用于最终候选版验收。

## 5. 处理预设

- **均衡（推荐）**：适合大多数汽车成片；
- **速度优先**：更保守地进入自动处理，适合车牌清晰的大批次；
- **精细处理**：降低自动检测阈值，检出更多候选，也可能增加复核数量。

预设保存在本机，对下一次启动继续生效；批次运行中不能切换。

## 6. 中断恢复

应用异常退出时，检测、修复或写入中的任务会在下次启动时回到“排队中”。进入任务
历史并点击“重新处理”即可恢复。已经成功写出的结果不会被覆盖。

## 7. 监视文件夹

在设置页登记本地磁盘文件夹后，应用会持续监视这些文件夹，发现新增或修改的
JPEG/PNG/TIFF 照片时自动入队处理。适合商拍现场持续倒入素材，或批量后期工作流中
持续接收照片的场景。

进入设置页的“监视文件夹”区块，点击“添加监视文件夹”选择本地磁盘上的文件夹即可
登记。每个文件夹可单独启用、停用或移除。应用启动时会异步扫描已登记的文件夹，把
其中未处理的照片自动入队；扫描在后台线程进行，不阻塞界面，可在监视面板上点
“取消扫描”中止，已收集的照片仍会正常处理。

监视运行时，命令栏会显示“监视中 (N)”脉冲徽章，N 为已捕获的张数，点击徽章跳转
到设置页管理监视列表。

需要注意：监视文件夹仅支持本地磁盘，不支持网络驱动器，包括 UNC 路径（如
`\\server\share`）和映射的网络盘，添加时会被拒绝。监视范围不包含 RAW 文件。已经
完成且未修改的照片不会重复处理；如果照片的修改时间或大小发生变化，会被当作修改过
而重新处理。取消当前批处理时，会同时清空监视队列中的待处理条目，当前正在处理的
单张照片会安全完成。

## 8. 批量后处理

处理完成后，应用可以按配置自动重命名输出文件、叠加水印并填写 EXIF 元数据，方便
商拍交付直接归档。后处理默认关闭，需要在设置页的“批量后处理”区块显式启用。

命名模板支持以下占位符：

- `{original}`：原文件名（不含扩展名）；
- `{ext}`：原扩展名；
- `{seq:03}`：批次内三位序号，从 001 起，遇同名冲突自增；
- `{client}`：当前项目对应的客户名称，未选项目时留空；
- `{date}`：处理日期，格式 YYYY-MM-DD。

水印支持两种类型，可在“水印类型”切换：

- **文字水印**：自定义文字内容、字号、颜色，适合版权署名；
- **图片水印**：选择本地 PNG/JPG/BMP/TIFF 图片作为 Logo 水印，可调整缩放比例
  （相对原图短边 5%–100%，默认 20%）。

两种类型共享透明度（0%–100%）和 9 宫格位置（左上、上中、右上、左中、居中、
右中、左下、下中、右下）配置。EXIF 元数据支持 Artist、Copyright、ImageDescription
三个字段；仅 JPEG 和 TIFF 会写入，PNG 不支持 EXIF，会自动跳过对应步骤。

后处理在消除结果生成后单独执行，单张增量耗时不超过 500ms。如果后处理失败，原消除
结果仍会保留，不会阻塞整批处理；可在任务历史中查看失败原因并单独重试。

## 9. 项目预设

按客户或项目保存完整预设，包含处理参数、后处理配置和输出目录规则。切换项目时一键
套用，避免每次重新调整。批处理页顶部新增“当前项目”选择器，下拉切换后会立即套用
对应预设；选择“无项目”时使用全局默认设置。

在“当前项目”选择器旁打开“项目管理”对话框可进行新增、编辑和删除。每个项目可配置
输出目录的三种模式：

- **源文件旁**：写入源目录旁的 `车牌已消除` 文件夹（默认）；
- **项目子文件夹**：在 `车牌已消除` 下按项目名称创建子文件夹；
- **固定目录**：写入项目指定的本地磁盘路径。

删除项目时，已关联的任务记录会保留，仅把 `project_id` 置空（ON DELETE SET NULL）；
输出文件不会被移动或删除。旧任务如果缺少 `project_id`，在历史和详情中仍会正常显示，
只是不归属任何项目。

## 10. 历史搜索与对比

任务历史支持按文件名模糊搜索，并可按状态、日期范围和所属项目筛选；支持按项目或
日期分组浏览。500 条任务以内的查询响应不超过 200ms。

在历史详情中可打开“前后对比”视图（ComparisonView 组件）：原图与处理结果并排展示，
拖动中间滑块可平滑切换查看范围。键盘快捷键：`← / →` 移动滑块，双击图片进入全屏。
对比视图带有 ARIA slider 角色和键盘导航支持，可用 Tab 聚焦滑块后用方向键操作。

## 11. 获取支持

设置页可以导出诊断包。诊断包包含应用版本、运行环境、任务数量和轮转日志，不包含
照片、照片路径或任务数据库。

## 12. 关于本软件

点击顶部栏右侧的版本号按钮可打开“关于”对话框，查看软件版本号、AI 运行时、数据库
schema 版本和版权信息。该对话框只读取本地数据，不发起任何网络请求。按 `Esc` 或点击
对话框外的区域可关闭。
