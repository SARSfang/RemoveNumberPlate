# 消除车牌用户指南

## 1. 开始批处理

1. 打开“消除车牌”。
2. 把照片或文件夹拖到批处理页，也可以使用“选择照片/选择文件夹”。
3. 任务开始后，中央显示单张大图，底部胶片带显示整批照片。
4. 使用“原图 / 处理结果”切换预览；结果尚未生成时会自动回到原图并说明原因。
5. 点击胶片带中的照片可固定预览；按 `F` 恢复跟随当前处理项。
6. 任务完成后，在右侧详情中打开源目录旁的 `车牌已消除` 文件夹。

支持 JPEG、PNG、TIFF；扫描文件夹时会递归寻找照片。软件不会覆盖原片，同名结果会
自动追加 `_clean_2`、`_clean_3` 等后缀。

### 批处理快捷键

- `Ctrl+O`：添加照片；
- `← / →`：浏览胶片带；
- `Home / End`：选择第一张或最后一张；
- `1 / 2`：切换原图或处理结果；
- `F`：恢复自动跟随。

批次运行时“添加照片”保持可见但会禁用，避免改变正在执行的任务队列。

## 2. 理解任务状态

- **已完成**：已生成结果，可以打开输出目录。
- **待复核**：检测存在低置信度、贴边、重叠等风险，原片尚未修改。
- **未发现车牌**：自动检测没有找到车牌；可以在任务历史中选择“手动标记”。
- **失败**：单张照片处理失败，不会中断整个批次；可在任务历史中重新处理。
- **排队中**：应用上次被中断的任务，可在任务历史中重新处理。

## 3. 调整每张照片的消除区域

在批处理主预览中选择任意一张已经停止处理的照片，点击右上角“调整区域”。低置信度、
贴边或异常检测照片也可以从“待复核”集中进入同一个编辑器。

- 四点框：分别拖动四个角点，让边线贴合车牌透视；
- 边缘：默认向外增加 8%，可在 -15% 到 +35% 间按 1% 调整；
- 新增车牌框：一张照片有多个车牌或漏检时点击新增；
- 画笔/橡皮擦：精修掩码边缘；
- 删除车牌框：移除误检区域；
- 撤销、重做和恢复自动框；
- 鼠标滚轮缩放，按住空格拖动画布；
- `[` / `]` 或按钮切换上一张、下一张。

点击“生成临时预览”后，AI 结果只保存在应用缓存，不会进入输出文件夹。可以在
“原图与区域 / 临时结果”间切换，选择“继续调整”或“保存新结果”。只有保存时才在
`车牌已消除` 文件夹生成新版本；原图和旧结果都不会覆盖。退出或重新编辑会让旧临时
预览失效。

## 4. 免安装测试版

开发测试时不必反复安装和卸载。关闭正在运行的软件后，在项目根目录执行：

```powershell
.\packaging\build_preview.ps1
```

以后始终双击根目录的 `启动测试版.cmd`。它只启动 `dist\preview` 中的固定测试版，
不会写安装记录或创建卸载项。安装程序只用于最终候选版验收。

## 5. 处理预设

- **均衡（推荐）**：适合大多数汽车成片；
- **速度优先**：更保守地进入自动处理，适合车牌清晰的大批次；
- **精细处理**：降低自动检测阈值，检出更多候选，也可能增加复核数量。

预设保存在本机，对下一次启动继续生效；批次运行中不能切换。

## 6. 中断恢复

应用异常退出时，检测、修复或写入中的任务会在下次启动时回到“排队中”。进入任务
历史并点击“重新处理”即可恢复。已经成功写出的结果不会被覆盖。

## 7. 获取支持

设置页可以导出诊断包。诊断包包含应用版本、运行环境、任务数量和轮转日志，不包含
照片、照片路径或任务数据库。
