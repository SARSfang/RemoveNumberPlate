# 故障排除

## 启动时提示已恢复任务历史或设置

应用会在首次启动时检查任务数据库和设置文件。只有 SQLite 明确认定数据库损坏，
或设置 JSON 无法解析时，原文件才会被改名保留，并创建新的安全文件。照片和已经
输出的结果不会被移动或删除。可以继续使用应用；如需排查原因，请在设置页导出
诊断包。

## 应用无法打开

1. 重新运行安装程序，确保 Microsoft Edge WebView2 Runtime 安装成功。
2. 确认系统为 64 位 Windows 10 1809 或更高版本。
3. 查看 `%LOCALAPPDATA%\SARSfang\RemoveNumberPlate\Logs\application.log`。
4. 如果仍然失败，保留日志并重新安装；卸载不会删除照片和输出。

## 预览显示“无法加载”

预览失败不会中断后台批处理。先确认原片仍位于原位置；如果查看“处理结果”，还要
确认该照片已完成且输出文件仍存在。点击重试或切回“原图”。任务记录存在但文件被
移动时，任务历史会保留记录并禁用依赖该文件的操作。

## 小窗口看不到照片详情

窗口宽度低于 1180 像素时，右侧详情会折叠为预览右上角的“详情”按钮。按 `Esc`
可关闭详情抽屉并把焦点返回按钮。1040×680 是支持的最小窗口尺寸。

## 模型状态显示失败

安装目录中的模型会在使用前进行 SHA-256 校验。不要手工替换 `_internal\models` 中的
文件。重新运行同版本安装程序可以修复缺失或损坏的程序文件。

## 某张照片失败

- 其他照片会继续处理；
- 在任务历史中把鼠标放在照片名称上可以查看错误摘要；
- 确认源照片仍存在、没有被其他程序独占、输出目录可写；
- 点击“重新处理”；若重复失败，导出诊断包。

## 没有检测到车牌

在批处理主预览或任务历史中选择照片并进入“调整区域”，点击“新增车牌框”，再拖动
四个角点贴合完整车牌及边框。

## 处理结果边缘不自然

进入“调整区域”，先拖动四个角点贴合车牌透视。若残留边框，把“边缘”从默认 +8%
逐步增加；若吞掉车灯、格栅或车身折线，则减小到 0% 或负值。画笔适合补充固定螺丝
和阴影，橡皮擦用于保护紧邻结构。每次先生成临时预览，满意后再保存新结果。

## 如何避免反复安装和卸载

日常测试运行 `packaging\build_preview.ps1`，然后双击根目录的 `启动测试版.cmd`。
重新构建前先关闭程序。`dist\preview` 与正式安装目录相互独立，不会修改安装状态、
任务历史、设置或已经输出的照片。

## 诊断包内容

诊断 ZIP 不包含照片像素、照片路径、EXIF、车牌文字或 `jobs.sqlite3`。发送前仍可以
自行解压检查 `diagnostics.json` 和 `logs`。
