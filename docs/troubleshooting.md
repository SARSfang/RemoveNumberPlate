# 故障排除

## 主题切换不生效

应用通过 `prefers-color-scheme` 媒体查询自动跟随系统主题。如果切换系统主题后应用没有跟随：

1. 确认 Windows 版本 ≥ 10 1809（支持 `prefers-color-scheme`）。
2. 打开 **Windows 设置** → **个性化** → **颜色**，确认"选择模式"已切换为"深色"或"浅色"。
3. 重启应用；WebView2 通常会即时响应系统主题变化。
4. 如果仍不生效，检查 WebView2 Runtime 版本 ≥ 90（可在"关于"对话框查看 AI 引擎信息确认运行环境）。

## 启动时提示已恢复任务历史或设置

应用会在首次启动时检查任务数据库和设置文件。只有 SQLite 明确认定数据库损坏，
或设置 JSON 无法解析时，原文件才会被改名保留，并创建新的安全文件。照片和已经
输出的结果不会被移动或删除。可以继续使用应用；如需排查原因，请在设置页导出
诊断包。

## 应用无法打开

1. 重新运行安装程序，确保 Microsoft Edge WebView2 Runtime 安装成功。
2. 确认系统为 64 位 Windows 10 1809 或更高版本。
3. 查看 `%LOCALAPPDATA%\SARSfang\RemoveNumberPlate\Logs\application.log`。
4. 如果仍然失败，保留日志并重新安装；卸载不会删除照片和输出。

## 预览显示“无法加载”

预览失败不会中断后台批处理。先确认原片仍位于原位置；如果查看“处理结果”，还要
确认该照片已完成且输出文件仍存在。点击重试或切回“原图”。任务记录存在但文件被
移动时，任务历史会保留记录并禁用依赖该文件的操作。

## 小窗口看不到照片详情

窗口宽度低于 1180 像素时，右侧详情会折叠为预览右上角的“详情”按钮。按 `Esc`
可关闭详情抽屉并把焦点返回按钮。1040×680 是支持的最小窗口尺寸。

## 模型状态显示失败

安装目录中的模型会在使用前进行 SHA-256 校验。不要手工替换 `_internal\models` 中的
文件。重新运行同版本安装程序可以修复缺失或损坏的程序文件。

## 某张照片失败

- 其他照片会继续处理；
- 在任务历史中把鼠标放在照片名称上可以查看错误摘要；
- 确认源照片仍存在、没有被其他程序独占、输出目录可写；
- 点击“重新处理”；若重复失败，导出诊断包。

## 没有检测到车牌

在批处理主预览或任务历史中选择照片并进入“调整区域”，点击“新增车牌框”，再拖动
四个角点贴合完整车牌及边框。

## 处理结果边缘不自然

进入“调整区域”，先拖动四个角点贴合车牌透视。若残留边框，把“边缘”从默认 +8%
逐步增加；若吞掉车灯、格栅或车身折线，则减小到 0% 或负值。画笔适合补充固定螺丝
和阴影，橡皮擦用于保护紧邻结构。每次先生成临时预览，满意后再保存新结果。

## 如何避免反复安装和卸载

日常测试运行 `packaging\build_preview.ps1`，然后双击根目录的 `启动测试版.cmd`。
重新构建前先关闭程序。`dist\preview` 与正式安装目录相互独立，不会修改安装状态、
任务历史、设置或已经输出的照片。

## 诊断包内容

诊断 ZIP 不包含照片像素、照片路径、EXIF、车牌文字或 `jobs.sqlite3`。发送前仍可以
自行解压检查 `diagnostics.json` 和 `logs`。

## 监视文件夹不工作

依次确认：文件夹路径仍是本地磁盘路径（不是网络驱动器或已映射的网络盘）；该文件夹
在设置页中没有被禁用；查看设置页是否显示错误状态。网络驱动器（包括 UNC 路径和映射
网络盘）不被支持，添加和启动扫描时都会被跳过。

## 监视文件夹被删除后如何恢复

被删除的文件夹会被自动标记为错误状态并停用，不会从列表中移除。恢复文件夹后（例如
重新创建或重新挂载本地磁盘），在设置页将该条目重新启用即可，不需要重新添加。

## 启动扫描卡住

启动扫描在后台线程进行，通常很快完成。如果需要中止，可在监视面板上点“取消扫描”，
已经收集的照片仍会进入处理队列。启动扫描仅在应用启动时进行一次，结束后不会重复
触发；后续新增照片由实时监视捕获。

## 后处理输出文件名不正确

依次检查：命名模板中的占位符拼写是否正确（`{original}`、`{ext}`、`{seq:03}`、
`{client}`、`{date}`）；`{seq:03}` 在遇到同名冲突时会自动自增，序号跨批次不连续属
正常行为；当前项目未选择时 `{client}` 留空，文件名中可能出现连续下划线或空段。在
设置页“批量后处理”区块修改模板后，仅对新处理的任务生效，已生成的文件不会自动
重命名。

## 水印不显示

确认设置页“批量后处理”中水印已启用且水印类型选择正确：

- **文字水印**：文字内容不能为空；透明度过低（接近 0）时水印近乎不可见，可先调到
  50% 验证；字号过大可能超出图片范围导致显示异常，可适当减小。
- **图片水印**：确认已通过“选择图片”按钮选取本地图片文件；若水印图片被移动或删除，
  渲染会自动跳过并保持原消除结果不变。仅支持 PNG/JPG/BMP/TIFF 等常见图片格式，
  不支持矢量图（SVG）或 PSD 工程文件。缩放比例过小（如 5%）时水印几乎不可见，
  可调至 20% 以上验证。

水印仅在启用了后处理的任务上叠加，未启用后处理的批次不会生成水印。

## EXIF 元数据未写入

确认输出图片格式为 JPEG 或 TIFF，PNG 不支持 EXIF 写入，会自动跳过对应步骤；确认
Artist、Copyright、ImageDescription 三个字段中至少有一个不为空；字段值全为空时
不写入任何 EXIF。后处理失败不会阻塞批处理，原消除结果仍会保留，可在任务历史中
查看失败原因并单独重试。

## 项目预设切换后参数未更新

确认项目已在“项目管理”对话框中保存（新增或编辑后需点击保存才生效）；检查批处理页
顶部“当前项目”选择器是否已切到目标项目，切换后会立即套用对应预设。如果预设中
包含后处理配置但设置页显示后处理仍关闭，确认该项目保存时后处理开关已开启。批次
运行中不能切换项目，需等当前批次完成或取消。

## 历史搜索无结果

检查筛选条件是否过于严格：状态、日期范围和项目三个筛选条件叠加后可能没有匹配项；
确认任务确实存在且未被清理。搜索框为文件名模糊匹配，输入过长的字符串可能匹配
失败，可尝试缩短关键词。如果按项目筛选无结果，确认该项目的任务没有被删除（删除
项目后任务保留但 `project_id` 置空，会从项目筛选中消失，可在“无项目”下查看）。
